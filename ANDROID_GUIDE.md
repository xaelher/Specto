## 1. Где взять APK-файл приложения

Приложение Specto устанавливается на оба телефона (телефон Ученика и телефон Наблюдателя).

### Вариант А. Скачать готовый APK (Рекомендуется — проще всего)
1. Откройте страницу репозитория проекта на GitHub в браузере телефона.
2. В правой колонке перейдите в раздел **Releases** (Релизы).
3. Скачайте файл **`Specto.apk`** и установите его на оба устройства (при необходимости разрешите установку из неизвестных источников в настройках Android).

---

### Вариант Б. Собрать APK самостоятельно на ПК
Если вы хотите собрать APK из исходного кода самостоятельно:
1. Убедитесь, что на компьютере установлены **Git** и **Flutter SDK**.
2. В терминале выполните сборку:
   ```bash
   git clone https://github.com/xaelher/Specto.git
   cd specto/frontend
   flutter pub get
   flutter build apk --release
   ```
3. Готовый APK-файл будет находиться по пути:
   ```
   frontend/build/app/outputs/flutter-apk/app-release.apk
   ```
4. Отправьте файл на телефоны и установите.

## 2. Как получить бесплатный вечный интернет-адрес (Ngrok)

Чтобы сервер был доступен через **мобильный интернет 4G/5G** и телефон наблюдателя мог подключаться из любой точки мира, используется сервис **Ngrok**. Он предоставляет **бесплатный постоянный интернет-домен**:

1. Перейдите на сайт **[https://dashboard.ngrok.com](https://dashboard.ngrok.com)** и зарегистрируйтесь (можно в 1 клик через Google/GitHub аккаунт).
2. В меню слева откройте **Your Authtoken**:
   - Скопируйте ваш токен (длинная строка из букв и цифр).
3. В меню слева откройте **Domains** (Домены):
   - Нажмите кнопку **New Domain** (или **Create Domain**).
   - Вам бесплатно выдадут постоянный домен (например, `my-specto.ngrok-free.app`).
   - Скопируйте этот домен.
4. **Всё готово!** Эти данные понадобятся один раз при первом запуске скрипта сервера.

## 3. Как запустить сервер на Android-телефоне (Termux)

Вам **не нужен компьютер**: сервер Specto (Django + SQLite) легко работает в фоновом режиме на Android-телефоне (например, на телефоне родителя или ученика).

### Шаг 1. Установка Termux
> ⚠️ **Важно:** Не устанавливайте Termux из Google Play (там устаревшая версия).
* Скачайте актуальный Termux с официального каталога **F-Droid**:  
  👉 **[https://f-droid.org/ru/packages/com.termux/](https://f-droid.org/ru/packages/com.termux/)**
* Установите и откройте приложение Termux.

---

### Шаг 2. Первичная установка и запуск в одну строчку
Вставьте следующую команду в Termux и нажмите **Enter**:

```bash
pkg update -y && pkg install python git openssh -y && git clone https://github.com/xaelher/Specto.git && cd specto && bash start_android_server.sh
```

---

### Шаг 3. Выбор режима в интерактивном меню:
Скрипт спросит режим запуска:
* **Нажмите `1` (Постоянный интернет-адрес через Ngrok — Рекомендуется):**
  - Вставьте скопированный `NGROK_AUTHTOKEN`.
  - Вставьте скопированный `NGROK_DOMAIN` (например `my-specto.ngrok-free.app`).
  - Скрипт сохранит эти настройки в файл `backend/.env` и при всех последующих запусках сервер будет **сразу** подниматься на вашем личном постоянном адресе без лишних вопросов!
* **Или нажмите `2` (Быстрый туннель Pinggy без регистрации):**
  - Мгновенно поднимет публичный интернет-туннель через SSH и покажет готовую ссылку `https://...pinggy.link`.
* **Или нажмите `3` (Только локальный Wi-Fi):**
  - Для работы без интернета, когда оба устройства подключены к одному роутеру.

---

### Шаг 4. Защита от засыпания (Wakelock)
Чтобы Android не отключал сервер при выключении экрана:
1. Опустите шторку уведомлений Android сверху вниз.
2. В постоянном уведомлении Termux нажмите кнопку **`Acquire wakelock`**.

---

### Повторный запуск сервера (в следующие разы)
Просто откройте Termux и введите:
```bash
cd ~/specto && bash start_android_server.sh
```
Сервер автоматически запустится на вашем постоянном интернет-домене.

## 4. Как запустить сервер на компьютере Windows в 1 клик

Если вы хотите, чтобы сервер работал на домашнем ПК:

1. Скачайте репозиторий проекта на компьютер:
   ```bash
   git clone https://github.com/xaelher/Specto.git
   ```
2. Откройте папку проекта и **дважды кликните по файлу `START_SERVER.bat`**.
3. При первом запуске выберите Режим **1** и вставьте токен и домен с `dashboard.ngrok.com`.
4. Сервер запустится и покажет публичный интернет-адрес `https://my-specto.ngrok-free.app`.

## 5. Как подключить оба телефона (Ученика и Наблюдателя)

Теперь, когда сервер работает в интернете, телефоны могут находиться **в любой точке мира** (один на 4G мобильном интернете, другой дома или в школе):

1. Откройте приложение **Specto** на телефоне.
2. На экране входа в правом верхнем углу нажмите на иконку шестерёнки (**⚙️**).
3. В диалоговом окне укажите ваш интернет-домен (например: `my-specto.ngrok-free.app`).
   > *Примечание: префикс `https://` и суффикс `/api` приложение подставляет автоматически.*
4. Нажмите **Сохранить**.
5. Повторите то же самое на втором телефоне!

*(Если сервер запущен в Termux на ЭТОМ же телефоне, на нём можно нажать кнопку «Этот телефон (127.0.0.1:8000)»).*

---

### Начало работы:
1. **Ученик**: нажимает *«Зарегистрировать аккаунт»* → выбирает роль **Ученик** → заполняет имя, класс, логин и пароль.
2. **Наблюдатель**: нажимает *«Зарегистрировать аккаунт»* → выбирает роль **Наблюдатель** → заполняет данные.
3. **Связка**:
   - Наблюдатель в меню нажимает *«Список учеников»* → *«Добавить ученика»* → находит ученика по имени/логину и жмёт *«Добавить»*.
   - Ученик в меню нажимает *«Наблюдатель»* → в блоке *«Входящие запросы»* нажимает *«Принять»*.
4. Готово! Теперь родитель видит дневник, оценки и банк успеваемости в реальном времени из любой точки мира.

## 6. Частые вопросы и решение проблем

* **Вопрос: При входе пишет «Ошибка подключения. Проверь интернет».**  
  *Ответ:*  
  1. Проверьте, запущен ли сервер в Termux или на ПК (в консоли должен быть зелёный статус с адресом `https://...`).  
  2. Проверьте адрес в шестерёнке (⚙️) — убедитесь, что домен совпадает с доменом вашего Ngrok.  
  3. В приложении уже встроены заголовки `ngrok-skip-browser-warning`, поэтому страница-заглушка Ngrok не блокирует запросы.

* **Вопрос: Где веб-панель управления и сброса паролей?**  
  *Ответ:*  
  Откройте в браузере любого устройства адрес: `https://<ВАШ_ДОМЕН_NGROK>/admin/`  
  Логин: `admin`  
  Пароль: `admin123`
