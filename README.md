> 📱 **[Инструкция: Как установить APK и запустить сервер на Android-телефоне или ПК (ANDROID_GUIDE.md)](./ANDROID_GUIDE.md)**

> **Specto** — Приложение на Андроид на подобие электронного дневника с системой вознагражднния. Создан для личных целей. Может быть модернизирован в будущем. Версия 1.0 включает в себя роли ученика и наблюдателя, а также историю оценок.
Доступен только русский язык интерфейса.

> **Specto** - An application on Android similar to an electronic school diary, featuring a reward system. It was created for personal use and may be upgraded in the future. Version 1.0 includes roles for a student and an observer, as well as a history of grades. Only the Russian interface language is available.
